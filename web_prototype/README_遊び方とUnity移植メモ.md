# Nade♡Me — 仮想デスクトップ型 育成交流ゲーム 試作版

> 2026-11-13制作。Unity/uGUIに移す前の**ブラウザ動作プロトタイプ**です。ゲーム本編と確定したキャラクター設定ではありません。

## 遊び方

1. このフォルダ内の `index.html` をChrome・Edgeなどで開きます。単独HTML版 `NadeMe_desktop_遊べる試作版.html` は画像も内蔵しています。
2. **好感度ウィンドウ**はメイン左上、**設定ウィンドウ**は右上に重なって初期表示されます。上のタイトルバーをドラッグして位置を移動できます。
3. 各ウィンドウの `×` で閉じ、下の黄色いタスクバーや左のデスクトップアイコンで開き直せます。クリックしたウィンドウが前面に来ます。
4. メインの上部タブで3人を切り替えます。ゆる以外は**仮のキャラクター**です。
5. `✋` モードで立ち絵の **頭／ほっぺ／肩** の3か所をタップ・なでると反応します。判定位置はキャラごとに違います。
6. セリフ欄下の3択を選ぶと好感度が増減します。`✎` モードでは筆談による短いローカル会話ができます。
7. 右下の `★` からキャラごとに異なるミニゲームを遊べます。
8. 1日あたり5回行動すると休憩が必要です。タスクバーの `START` → `今日は帰る` で次の日へ移れます。
9. 好感度は -100 〜 +100。高低に応じて簡易エンディング（±80）があります。
10. 進捗はブラウザのローカル保存領域にセーブされます。`START` → `セーブを初期化` でやり直せます。

※ 本物のAIによる自由会話ではありません。筆談は入力キーワードに応じた分岐デモです。

## レイアウト仕様（1920×1080基準）

| 要素 | サイズ | 初期位置（左上・画面基準） | 備考 |
|---|---|---|---|
| デスクトップ | 1920×1080 | (0, 0) | 背景 / ショートカット |
| メインウィンドウ | 1320×990 | (300, 10) | 比率 4:3、最初は背面 |
| 好感度ウィンドウ | 470×210 | (88, 90) | メイン左上に重ねる |
| 設定ウィンドウ | 600×450 | (1255, 100) | メイン右上に重ねる |
| タスクバー | 1920×72 | (0, 1008) | 前面固定 |

ウィンドウ上部のタイトルバーは48px、左右・下枠は8px。サイズは変更不可。タイトルバーが完全に画面外に消えないようにドラッグを制限しています。ブラウザ版は画面全体を比率維持で縮小するため、ディスプレイ解像度が1920×1080以外でもウィンドウ間の相対配置が保たれます。

## 画像・UIアセット

- `assets/yuru_bust.png`：既存の「ゆる」イラストから作った、**透過・上半身**の仮立ち絵。最終差分制作前の仮素材です。
- `assets/expr_*.png`：「ゆる」の表情サムネイル。会話・なでる際に切り替わります。
- `assets/character_02.png` と `assets/character_03.png`：2人目・3人目の**仮デザイン**。SVGソースも併記。
- `references/layout_sketch.png` と `references/color_block_reference.png`：渡された2つのUIラフ（レイアウトと重なり方の参照用）。

実際にUnityへ移す際は、CLIP STUDIO PAINTで制作したタイトルバー／枠／ボタン／背景／キャラ立ち絵の各PNGに差し替え、SpriteのImport Typeを `Sprite (2D and UI)` にします。仮キャラの絵柄・台詞・禁止事項・エンディング内容は**正式設定ではありません**。

## Unity uGUIでの推奨ヒエラルキー

```text
Canvas (Screen Space - Overlay)
├── DesktopBackground (Image)
├── DesktopIcons (Button ×3)
├── WindowsRoot (RectTransform)
│   ├── MainWindow (1320×990)
│   │   ├── TitleBar (48px: Image + TextMeshProUGUI + Button)
│   │   ├── CharacterTabs (3×Button)
│   │   ├── StageView
│   │   │   ├── CharacterImage (Image / preserveAspect)
│   │   │   └── NadePoints (3×Button)
│   │   ├── DialoguePanel (TextMeshProUGUI / 選択肢 / InputField)
│   │   └── ToolButtons (なでる・筆談・ミニゲーム)
│   ├── AffectionWindow (470×210)
│   └── SettingsWindow (600×450 / Slider×2)
├── Taskbar (1920×72, 常時最前面)
└── ModalLayer (エンディング・ミニゲーム)
```

- Canvas Scaler: `Scale With Screen Size`、Reference Resolution = `(1920, 1080)`。
- ウィンドウはそれぞれ `RectTransform` サイズ固定、Anchor / Pivotを上・左に統一すると初期配置を合わせやすいです。
- `MainWindow`: anchoredPosition = `(300, -10)`。`AffectionWindow`: `(88, -90)`。`SettingsWindow`: `(1255, -100)`（いずれも左上基準）。
- Taskbar は下側固定で height = 72。`WindowsRoot` 内で `SetAsLastSibling()` を使い前面移動を実装し、Taskbarは別レイヤーに置いて覆われないようにします。
- タイトルバーのドラッグは `IBeginDragHandler` / `IDragHandler` または `IPointerDownHandler` を使用し、Canvasスケールを考慮して座標変換します。
- キャラごとの3つのなでポイントは**画像と独立した正規化座標**で定義。イラスト差し替え時も当たり判定だけ再調整できる設計を推奨します。
- 会話イベント、禁止事項、ミニゲームは `ScriptableObject` または JSONで各キャラのデータとして分けると後から設定変更がしやすくなります。

## 実装済みと未実装

**実装済み**：3ウィンドウ初期配置・移動・重なり順・開閉・タスクバーから再表示、好感度（-100〜100）、3キャラ切り替え、3種類のなでポイント、筆談入力、3択分岐、3種のミニゲーム、日数と行動回数、簡易エンディング、簡易BGM/SE、ブラウザへの進行保存。

**今後の正式開発で必要**：Unityシーン/uGUI実装、本物のキャラ立ち絵差分、設定済み世界観に沿ったストーリー、禁止事項の正式ルール、ミニゲーム本制作、AI会話APIサーバー、UI完成素材、マルチエンディング本文、セーブデータ仕様、操作しやすさ/アクセシビリティ検証。

### 優先順位メモ

1. **UI構造の固定**：ラフどおりの画面配置をUnityで再現し、ドラッグ・開閉・前面化を先に安定させる。
2. **データ構造の分離**：好感度、行動回数、3キャラのパラメーター、なで位置をシステムとして実装。
3. **コンテンツ差し替え**：キャラごとの立ち絵/表情/会話/禁止事項/ミニゲーム/分岐を正式設定で作り込む。

※ ラフではメインウィンドウ上端がタスクバーに近いほど縦に大きく、ほかのウィンドウが左右から重なる構図です。この試作版でも、色や細部より**位置・固定サイズ・重なり**を優先しました。


## Ver.3（ゆらゆらモーション）
- 3キャラの立ち絵全体を呼吸・左右揺れ・傾きでアニメーション
- キャラ別モーション速度と振幅（ゆる／ひまり／しずく）
- ステージ内のマウス位置にゆっくり追従
- なでる・会話・ミニゲームのリアクション（弾む／少ししょんぼり）
- なでポイントを立ち絵と同時に変形して判定ずれを防止
- 設定ウィンドウの「立ち絵のゆらぎ」スライダーを0%にすると停止
- prefers-reduced-motion による自動抑制

**注意:** 本物のLive2Dではありません。髪、顔、体を個別に動かすには、レイヤー分割済みの原画とリギングが必要です。現在の版は単一の透過立ち絵を2D/3Dトランスフォームで動かす演出です。
